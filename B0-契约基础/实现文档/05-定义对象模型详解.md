## 已添加的定义对象

### 1. AgentSpec（Agent 定义）

**作用**：定义一个稳定专业 Agent 的职责、边界和所有运行依赖

```python
class AgentSpecSpec(StrictModel):
    purpose: NonEmptyString           # Agent 目的
    domain: str                       # 业务领域
    goals: list[str]                  # 目标列表
    non_goals: list[str]              # 非目标列表
    input_schema_ref: SchemaRef       # 输入 Schema
    output_schema_ref: SchemaRef      # 输出 Schema
    prompt_package_ref: ResourceRef   # Prompt 包引用
    context_policy_ref: ResourceRef   # Context 策略引用
    model_policy_ref: ResourceRef     # 模型策略引用
    loop_profile_ref: ResourceRef     # Loop 配置引用
    permission_profile_ref: ResourceRef  # 权限配置引用
    skill_bindings: list[Binding]     # 技能绑定
    tool_bindings: list[Binding]      # 工具绑定
    memory_policy: MemoryPolicy       # 记忆策略
    budget_defaults: Budget           # 默认预算
    approval_defaults: ApprovalDefaults  # 审批默认配置
    concurrency_policy: ConcurrencyPolicy  # 并发策略
    eval_suite_refs: list[ArtifactRef]  # 评估集引用
```

**关键验证规则**：
- `prompt_package_ref` 必须引用 PromptPackage
- `context_policy_ref` 必须引用 ContextPolicy
- `model_policy_ref` 必须引用 ModelPolicy
- `loop_profile_ref` 必须引用 LoopProfile
- `permission_profile_ref` 必须引用 PermissionProfile

**示例场景**：
- 售前咨询 Agent
- 直播切片 Agent
- 自媒体运营 Agent

### 2. SkillManifest（技能清单）

**作用**：描述一个可移植 Skill Bundle 的平台级元数据

```python
class SkillManifestSpec(StrictModel):
    portable_name: str                # 与 SKILL.md 名称一致
    description: str                  # 描述（至少20字符）
    domain: list[str]                 # 所属领域
    tags: list[str]                   # 检索标签
    trigger_examples: TriggerExamples # 正例和反例
    required_tools: list[ToolRequirement]  # 所需工具
    required_skills: list[SkillRequirement]  # 技能依赖
    conflicts_with: list[ResourceRef]  # 冲突技能
    permission_requirements: list[PermissionRequest]  # 权限需求
    risk_level: RiskLevel             # 风险级别
    runtime_requirements: RuntimeRequirements  # 运行时需求
    context_budget: ContextBudget     # Context 预算
    bundle_artifact_ref: ArtifactRef  # 不可变发布包
    source_repository: SourceRepository  # 源码仓库
    eval_summary: EvalSummary         # 评估摘要
    provenance: DefinitionProvenance  # 来源
```

**关键验证规则**：
- `conflicts_with` 必须引用 SkillManifest
- `required_skills` 不能有重复
- Hermes 提案只能是 `proposed` 或 `draft`
- `active` 状态必须通过安全和回归评估

**风险级别**：
| 级别 | 说明 |
|---|---|
| `low` | 低风险，无需特殊审批 |
| `medium` | 中等风险，可能需要审批 |
| `high` | 高风险，需要审批 |
| `critical` | 关键风险，必须审批 |

### 3. 辅助类型

#### MemoryPolicy（记忆策略）

```python
class MemoryPolicy(StrictModel):
    readable_scopes: list[ScopeType]  # 可读取的作用域
    writable_scopes: list[ScopeType]  # 可写入的作用域
    write_requires_approval: bool     # 写入是否需要审批
    max_retention_days: int           # 最大保留天数
    allow_cross_user: False           # 禁止跨用户（硬编码）
    allow_cross_tenant: False         # 禁止跨租户（硬编码）
```

**安全设计**：
- `allow_cross_user` 和 `allow_cross_tenant` 硬编码为 `False`
- 跨用户/租户记忆访问默认禁止

#### TriggerExamples（触发示例）

```python
class TriggerExamples(StrictModel):
    positive: list[str]  # 正例：应该触发的场景
    negative: list[str]  # 反例：不应该触发的场景
```

**作用**：
- 用于 Skill 触发判断
- 用于评估 Skill 触发准确率

#### RiskLevel（风险级别）

```python
class RiskLevel(StrEnum):
    LOW = "low"
    MEDIUM = "medium"
    HIGH = "high"
    CRITICAL = "critical"
```

## 关键设计决策

### 1. 为什么 AgentSpec 必须声明目标和非目标？

- **目标**：明确 Agent 应该做什么
- **非目标**：明确 Agent 不应该做什么
- 防止职责模糊和越界

### 2. 为什么 Skill 默认不可信？

```python
# Skill 中的自然语言可能包含提示注入
# 脚本可能产生真实副作用
# 因此：
# - Skill 只能请求权限，不能授予权限
# - Skill 脚本默认按不可信代码处理
# - active 状态必须通过安全评估
```

### 3. 为什么使用 ResourceRef 而不是字符串 ID？

```python
# ResourceRef 包含：kind + id + version + digest
# 好处：
# - 强类型，防止引用错误类型的资源
# - 精确版本，防止版本漂移
# - 摘要校验，防止内容篡改
```
