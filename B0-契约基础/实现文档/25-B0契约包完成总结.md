## 关键设计决策

### 1. 统一资源信封

```json
{
  "api_version": "agent-platform/v1alpha1",
  "kind": "AgentSpec",
  "metadata": { ... },
  "spec": { ... },
  "status": { ... }
}
```

### 2. 强类型 ID

```
agt_0198f6d0-7ef0-7b0e-a0d3-5f9c96c7f411
↑ 前缀    ↑ UUIDv7
```

### 3. 精确引用

```json
{
  "kind": "PromptPackage",
  "id": "prm_0198f6d0-...",
  "version": "1.0.0",
  "digest": "sha256:..."
}
```

### 4. 安全设计

- Deny 优先
- 跨租户默认拒绝
- Secret 不能进入 Context
- 高风险操作必须审批

### 5. 幂等控制

- Task: tenant + source + idempotency_key
- ToolCall: tool + target_resource + idempotency_key
