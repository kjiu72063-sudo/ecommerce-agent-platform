## 核心知识点总结

### 1. 15 个资源模型

**定义对象（8个）**：
| 模型 | 作用 | ID 前缀 |
|---|---|---|
| AgentSpec | Agent 定义 | `agt_` |
| SkillManifest | 技能清单 | `skl_` |
| ToolManifest | 工具清单 | `tol_` |
| PromptPackage | Prompt 包 | `prm_` |
| ModelPolicy | 模型策略 | `mpo_` |
| ContextPolicy | Context 策略 | `cpo_` |
| LoopProfile | Loop 配置 | `lop_` |
| PermissionProfile | 权限配置 | `pep_` |

**运行对象（7个）**：
| 模型 | 作用 | ID 前缀 |
|---|---|---|
| Task | 任务 | `tsk_` |
| AgentRun | Agent 运行 | `run_` |
| Checkpoint | 检查点 | `ckp_` |
| ToolCall | 工具调用 | `tcl_` |
| Approval | 审批 | `apr_` |
| Artifact | 产物 | `art_` |
| Event | 事件 | `evt_` |

### 2. 6 个状态机

| 状态机 | 状态数 | 终态数 |
|---|---|---|
| definition | 9 | 1 (archived) |
| task | 11 | 4 |
| agent-run | 13 | 4 |
| tool-call | 13 | 7 |
| approval | 7 | 4 |
| artifact | 6 | 1 (deleted) |

### 3. 关键设计原则

1. **双层校验**：JSON Schema + Pydantic
2. **定义对象不可变**：已发布对象不能原地修改
3. **Deny 优先**：权限决策 deny 始终优先
4. **幂等控制**：副作用操作必须幂等
5. **租约管理**：防止并发冲突
