# 第一步：项目配置文件说明

> 本节说明创建的配置文件及其作用

---

## 已创建的文件

### 1. pyproject.toml

**作用**：Python 项目的核心配置文件

```toml
[project]
name = "agent-platform-contracts"  # 包名称
version = "0.2.0"                  # 版本号
requires-python = ">=3.11"         # 要求 Python 3.11+

dependencies = [
    "pydantic>=2.0,<3.0",          # 核心依赖：Pydantic v2
]
```

**关键知识点**：
- Pydantic v2 是数据验证库，用于定义数据模型
- 我们使用 Pydantic 来定义所有 15 个核心资源对象
- Pydantic 会自动验证字段类型、约束条件

### 2. requirements-dev.txt

**作用**：开发环境依赖

```
pydantic>=2.0,<3.0    # 数据模型
jsonschema>=4.20      # JSON Schema 验证
pytest>=7.0           # 测试框架
```

### 3. __init__.py

**作用**：Python 包初始化文件

```python
"""Agent Platform B0 Contracts"""
__version__ = "0.2.0"
```

**关键知识点**：
- `__init__.py` 让 Python 把目录当作包
- 可以在这里定义包级别的变量和导入
