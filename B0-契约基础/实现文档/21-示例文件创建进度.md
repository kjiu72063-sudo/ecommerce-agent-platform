## 有效示例关键设计

### 1. 统一资源信封

```json
{
  "api_version": "agent-platform/v1alpha1",
  "kind": "AgentSpec",
  "metadata": { ... },
  "spec": { ... },
  "status": { ... }
}
```

### 2. 强类型 ID

```json
"id": "agt_0198f6d0-7ef0-7b0e-a0d3-5f9c96c7f411"
     ↑ 前缀    ↑ UUIDv7（版本号必须是 7）
```

### 3. 精确引用

```json
"prompt_package_ref": {
  "kind": "PromptPackage",
  "id": "prm_0198f6d0-...",
  "version": "1.0.0",
  "digest": "sha256:..."
}
```

### 4. 幂等控制

```json
"idempotency_key": "openclaw:feishu:message-12345"
```

### 5. 预算控制

```json
"budget": {
  "max_wall_time_seconds": 7200,
  "max_model_tokens": 800000,
  "max_cost_usd": "30.00"
}
```
