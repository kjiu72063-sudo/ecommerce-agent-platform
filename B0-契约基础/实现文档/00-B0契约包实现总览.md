## 二、文件作用详解

### 2.1 src/agent_platform_contracts/ - 核心 Python 包

| 文件 | 作用 | 重要程度 |
|---|---|---|
| `models.py` | **最核心** - 定义所有 15 个资源对象的 Pydantic 模型 | ⭐⭐⭐⭐⭐ |
| `state_machines.py` | 定义 6 个状态机的合法迁移 | ⭐⭐⭐⭐⭐ |
| `policies.py` | 实现权限、幂等、租约等策略函数 | ⭐⭐⭐⭐ |
| `sample_data.py` | 提供测试用的示例数据 | ⭐⭐ |

### 2.2 schemas/ - JSON Schema 文件

**作用**：跨语言的结构校验，任何语言都可以使用这些 Schema 验证数据

| 子目录 | 文件数量 | 说明 |
|---|---|---|
| `common/` | 2 | 公共类型（Scope、ActorRef、Budget 等） |
| `definitions/` | 8 | 定义对象（AgentSpec、SkillManifest 等） |
| `runtime/` | 7 | 运行对象（Task、AgentRun 等） |

### 2.3 examples/ - 示例文件

**作用**：用于测试和文档

- `valid/` - 15 个有效示例，必须通过 Schema 和 Pydantic 验证
- `invalid/` - 19 个无效示例，必须被拒绝并返回预期错误码

### 2.4 state-machines/ - 状态机 JSON

**作用**：状态机的 JSON 格式定义，与 Python 代码保持同步

### 2.5 conformance/ - 一致性测试

**作用**：31 项测试，确保所有实现符合 B0 契约
