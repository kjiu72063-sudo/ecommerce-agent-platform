# 02: 固定商品知识 JSON 与确定性检索 → EvidenceItem

**What to build:** 从绑定单商品的版本化 JSON 商品资料集检索字段/片段，返回可定位、可复现的 `EvidenceItem`。未来由商品运营团队维护已发布知识；V1 原型使用确定性检索。

**Blocked by:** 01

**Status:** completed

## 目标

- 提供固定、可复现的商品知识来源；
- 对单商品范围执行确定性检索；
- 将回答实际使用的内容转为带来源、版本、定位和摘要的 `EvidenceItem`；
- 检索结果可复现、可追溯。

## 输入 / 输出

- 输入：`ProductQuestion`（绑定单商品）、固定商品知识 JSON、检索查询或问题文本
- 输出：候选证据列表、被选用的 `EvidenceItem` 列表、检索跳过/无结果/冲突信号

## 涉及的契约

- `ProductKnowledgeSource` 来源标识、版本、字段/片段定位、摘要；
- `EvidenceItem` 来源、版本、定位、摘要、租户、商品归属；
- 确定性检索规则（关键词、同义词、排序、阈值），V1 暂不接入向量检索。

## 验收标准

- [ ] 给定固定 JSON 和单商品问题，能得到确定、可复现的候选证据；
- [ ] 检索结果的字段/片段能定位到 JSON 的具体字段或片段；
- [ ] 被选用的内容形成带版本、定位、摘要的 `EvidenceItem`；
- [ ] 仅使用商品运营团队标记为已发布的资料；
- [ ] 跨商品范围或跨租户检索默认拒绝。

## 拒绝 / 失败验收

- [ ] 无匹配结果返回明确"无证据"信号，不返回空而不说明；
- [ ] 多个来源对同一字段冲突时返回冲突信号；
- [ ] 商品、租户或来源版本缺失时返回明确错误。

## 明确不包含

- 答案生成和转人工判定（属于 04）；
- Context 组装（属于 03）；
- 幂等执行抑制（属于 09）；
- 向量数据库、外部 RAG 平台和真实商品中心接入；
- 任何业务写操作。
