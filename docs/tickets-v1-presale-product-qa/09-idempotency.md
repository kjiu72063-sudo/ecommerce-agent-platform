# 09: 幂等提交

**What to build:** 对同一 `ProductQuestion` 的重复提交提供明确幂等行为，避免重复创建不受控的 Task 或重复运行。

**Blocked by:** 03

**Status:** ready-for-agent

## 目标

- 使用 B0 幂等键约束重复提交；
- 同一租户、同一业务语义的重复请求返回既有结果或明确冲突；
- 不把幂等当成数据库偶然去重。

## 输入 / 输出

- 输入：相同或冲突的 ProductQuestion 与 idempotency key
- 输出：既有 Task/Run 引用、幂等冲突或明确校验错误

## 涉及的契约

- ProductQuestion 的 idempotency key；
- Task 创建和 run_ref 关联；
- 租户边界。

## 验收标准

- [ ] 相同租户、相同幂等键和相同请求重复提交不创建重复 Task；
- [ ] 重复请求返回可追溯的既有业务/技术引用；
- [ ] 相同幂等键但请求内容冲突时返回明确冲突；
- [ ] 不同租户不能通过相同幂等键互相命中。

## 拒绝 / 失败验收

- [ ] 幂等判断失败不会静默创建重复运行；
- [ ] 缺失或非法幂等键时明确拒绝输入。

## 明确不包含

- 分布式幂等基础设施；
- 消息队列去重；
- 业务回答质量和人工处置。
