## 端口契约

### `RetrievalPort`（src/presale/knowledge.py）
```python
class RetrievalPort(ABC):
    @abstractmethod
    def retrieve(self, question: ProductQuestion) -> RetrievalResult: ...
```
- 输入：`ProductQuestion`（含 `tenant_id`、`product_id`、`question_text`）。
- 输出：`RetrievalResult`（`status` ∈ matched/no_evidence/conflict，`evidence_items`，`reason_codes`）。
- 不变量：绝不返回跨租户/跨商品的证据；matched 必须有证据、no_evidence 必须无证据、conflict 至少两条。
- 失败：外部不可用时的行为由实现决定（严格失败或降级），见下。

实现：
- `DeterministicKnowledgeRetriever`（开发/最小闭环，默认）。
- `ExternalRetrieval`（src/presale/adapters/external_retrieval.py，外部检索环）。

### `GeneratorPort`（src/presale/answer.py）
```python
class GeneratorPort(ABC):
    @abstractmethod
    def generate(self, question, retrieval, *, run_ref, configuration_refs) -> AnswerDraft: ...
```
- 输入：question、scoped `RetrievalResult`、run_ref、configuration_refs。
- 输出：`AnswerDraft`（满足其不变量：run_ref 为 AgentRun、无证据需人工复核、人工复核需 reason_code）。
- 失败：必须抛 `AnswerGenerationError`，不返回不可信的草稿。

实现：
- `PresaleAnswerGenerator`（开发/最小闭环，默认）。
- `OpenAICompatibleGenerator`（src/presale/adapters/openai_generator.py，LLM 生成环）。

## 外部适配器的失败/降级语义

### `ExternalRetrieval`
- 传输成功 → 解析为 scoped 证据；空 → `NO_EVIDENCE` + `EXTERNAL_NO_EVIDENCE`。
- 传输抛错：
  - 有 `fallback` → 返回 fallback 结果并追加 `RETRIEVAL_DEGRADED` reason_code（可观测降级）；
  - 无 fallback → 抛 `RetrievalError`（`RETRIEVAL_CALL_FAILED`；未配置 transport 时 `RETRIEVAL_NOT_CONFIGURED`）。
- 跨租户/跨商品证据一律过滤，不泄漏。

### `OpenAICompatibleGenerator`
- 传输成功 → 提取 `choices[0].message.content` → 映射为 `AnswerDraft`；NO_EVIDENCE/CONFLICT 仍按不变量走人工复核。
- 传输抛错 → `AnswerGenerationError("LLM_CALL_FAILED")`；空响应 → `LLM_EMPTY_RESPONSE`；畸形 → `LLM_MALFORMED_RESPONSE`。

### 幂等/保留/装配
- 外部环不改变既有幂等状态机、30 天保留、租户隔离、`runtime.create_sqlite` 装配契约。
- 默认装配仍用确定性实现；外部适配器需显式注入才会产生外部副作用（零默认外部调用）。
