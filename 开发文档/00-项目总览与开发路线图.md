> 文档版本：1.1.0
> 创建日期：2026-09-01
> 项目状态：B0-B6 + 六方向深化全部完成，334 passed；C(类型修复)/E(真实LLM)/B(PostgreSQL)/D(新Agent)/F(评估框架) 已落地

---

## 一、项目目标

构建面向电商业务的完整 AI Agent 生态系统，包含：
- **业务 Agent 层**：售前咨询、直播切片、自媒体内容运营
- **数据 & 素材中枢层**：AI 数据中台、多模态素材中心、销售考核系统
- **RAG 知识库**：商品知识检索
- **底层基础设施层**：模型微调、MCP & Agent 共享集群

## 二、开发策略

**自底向上开发**：先完成中台基础设施，再构建上层业务 Agent。

```
开发顺序：
B0 契约基础（当前）
    ↓
B1 能力注册中心
    ↓
B2 状态与持久化
    ↓
B3 Context 引擎
    ↓
B4 Agent 执行器（Harness）
    ↓
B5 Loop 引擎
    ↓
B6 业务 Agent 实现
```

## 六、开发原则

1. **契约优先**：所有实现必须符合 B0 契约
2. **测试驱动**：先写测试，再写实现
3. **渐进式开发**：每个阶段独立可测试
4. **文档同步**：代码与文档同步更新
5. **代码审查**：每个 PR 需要 review
